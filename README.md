# 绿茵BIT · 北理工校园足球赛事管理系统

> 基于 PRD V1.0 的可运行软件实现：**多端移动前端 + 后端服务 + 云数据库 + 角色权限 + AI 识图**

## 一、这是什么

绿茵BIT 把校园足球赛事“报名 → 审核 → 抽签 → 排赛 → 录分 → 榜单”全流程搬进一个系统，并叠加两项正式产品能力：

1. **每场比赛技术统计**：双方首发/替补名单 + 竖版事件时间轴（进球、黄牌、红牌、换人的球员与时间）；
2. **手机号验证码账号体系**：注册即参赛球员，管理员可开通数据录入员；
3. **角色权限体系**：管理员（全能力）/ 数据录入员 / 参赛球员，赛事级指派 + 文件级权限 + 操作审计；
4. **整队报名**：每名球员分别提交手机号与学生卡照片，报名截止后名单锁定；
5. **AI 识图（赛程安排页）**：上传裁判报告，一次性识别双方首发/替补（号码+姓名）、比赛服颜色、比分、进球/换人/红黄牌时间轴与裁判名单，人工复核后一键落库、榜单自动重算。

前端为移动端优先的响应式 PWA（Android / iOS / 鸿蒙浏览器可直接使用，也可按 uni-app 路线打包三端原生应用）。

## 二、30 秒跑起来

环境要求：Node.js ≥ 22.5（已内置 SQLite，**无需 npm install**）。

```bash
# 方式一：命令行
cd server
node src/index.js

# 方式二：PowerShell（仓库根目录）
.\scripts\start.ps1
```

浏览器打开 **http://localhost:3000**。

手机同网演示：手机与电脑连同一 WiFi，访问 `http://<电脑局域网IP>:3000`。

> 首次启动自动写入演示数据。演示环境短信验证码会直接显示在页面并自动填入。

### 推荐演示路线

1. 用管理员手机号验证码登录 → 进入“2026 新生杯” → **球队报名** 审核整队名单；
2. 在“抽签分组”开始抽签 → “赛程安排”添加比赛；
3. 用数据录入员手机号登录 → 进入“联赛” → **赛程安排 → AI 识图（裁判报告）** → 载入示例裁判报告 → 识别完整名单/颜色/时间轴 → 复核 → 提交；
4. 新手机号走“注册”，体验验证码注册与整队报名；切换管理员查看“成员/操作日志”。

## 三、工程结构

```text
绿茵BIT/
├─ app/                 # 移动端优先前端（纯静态，PWA）
│  ├─ index.html
│  ├─ css/app.css
│  └─ js/
│     ├─ lib/           # API 封装 / UI 组件
│     └─ views/         # 登录、赛事、报名、分组、赛程、统计、AI、成员、日志
├─ server/              # 后端服务（Node.js，零运行时依赖）
│  ├─ src/
│  │  ├─ routes/        # 认证/用户/赛事/报名/分组/比赛/统计/AI/审计
│  │  ├─ services/      # AI 识图服务（Provider 抽象）
│  │  ├─ schema.sql     # 演示库 DDL（SQLite）
│  │  ├─ seed.js        # 演示数据
│  │  └─ index.js       # 入口
│  └─ data/             # 运行时生成（可删除，重启自动重建）
├─ database/schema.sql  # 云数据库正式 DDL（PostgreSQL + RLS）
├─ docs/                # 权限 / AI / 云数据库 / 多端 / API 文档
└─ scripts/             # 启动与自测脚本
```

## 四、实用脚本


### 关键技术点

- **本地演示**：Node 内置 SQLite + 内置 HTTP 服务，零依赖可跑；**云端**：`DB_DRIVER=pg` 一行切到 PostgreSQL（腾讯云/阿里云/Supabase）。
- **权限**：RBAC 能力矩阵 + `event_staff` 赛事指派 + 文件级鉴权 + `audit_log` 审计 + PostgreSQL RLS 兜底。
- **AI 识图**：`server/src/services/aiRecognition.js` 提供 demo / vision 双 Provider；无 Key 离线演示，配 Key 即接 qwen-vl-max、gpt-4o 等视觉模型（见 `.env.example`）。
- **数据一致性**：积分榜/射手榜为派生数据，由已完赛比赛实时计算，杜绝双写不一致。
