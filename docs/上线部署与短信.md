# 绿茵BIT · 公网发布与账号体系配置

## 一、先选发布方式

| 方式 | 链接形态 | 成本 | 适用场景 |
|---|---|---|---|
| 临时隧道（cloudflared / frp） | `https://xxxx.trycloudflare.com` | 免费 | 今天就要发同学，电脑保持开机 |
| 云服务器 + Docker + 域名 | `https://soccer.example.com` | 服务器约 30–60 元/月 + 域名 | 正式给同学长期使用（推荐） |
| 海外 PaaS（Zeabur / Railway 等） | 平台分配的 https 域名 | 免费额度或按月 | 不想折腾服务器，但国内访问可能偏慢 |

> 账号体系默认是**手机号 + 姓名 + 密码**，不需要任何短信资质即可上线。
> 短信验证码是可选能力：要走国内短信服务商，且签名/模板需要审核（约 3–5 天），这一步无法绕过。

## 二、真实短信接入（代码已支持，只需填 Key）

支持三种模式，改 `.env` 后重启即可：

### 1）腾讯云短信

```bash
SMS_MODE=tencent
TENCENT_SMS_SECRET_ID=你的SecretId
TENCENT_SMS_SECRET_KEY=你的SecretKey
TENCENT_SMS_APP_ID=1400xxxxxx
TENCENT_SMS_SIGN_NAME=你的短信签名
TENCENT_SMS_TEMPLATE_ID=你的模板ID
TENCENT_SMS_REGION=ap-guangzhou
```

申请步骤：
1. 腾讯云实名认证 → 开通短信服务；
2. 创建短信签名（网站/公众号/App 资质）；
3. 创建验证码模板，模板参数建议为 `{1}=验证码`、`{2}=有效期分钟`（与代码发送顺序一致）；
4. 建议创建 CAM 子账号密钥，只授予短信发送权限。

### 2）阿里云短信

```bash
SMS_MODE=aliyun
ALIYUN_SMS_ACCESS_KEY_ID=你的AccessKeyId
ALIYUN_SMS_ACCESS_KEY_SECRET=你的AccessKeySecret
ALIYUN_SMS_SIGN_NAME=你的短信签名
ALIYUN_SMS_TEMPLATE_CODE=SMS_123456789
ALIYUN_SMS_REGION_ID=cn-hangzhou
```

模板参数使用 `{"code":"123456"}`，模板内容需包含 `${code}`。

### 3）自建/第三方短信网关

```bash
SMS_MODE=webhook
SMS_WEBHOOK_URL=https://your-gateway.example.com/send
SMS_WEBHOOK_TOKEN=可选BearerToken
```

网关会收到 `POST {"phone":"138...","code":"123456","ttl":300}`。

### 未配置短信时

账号体系以**手机号 + 密码**为主，未配置短信也能正常上线，不需要任何短信资质。

- 本地演示：`SMS_MODE=demo`，验证码直接显示并自动填入，方便走通验证码登录流程；
- 生产环境（`NODE_ENV=production`）：演示验证码默认**关闭**，`/auth/send-code` 返回 `SMS_NOT_CONFIGURED`，
  这是有意为之——否则任何人只要知道手机号就能登录任意账号。需要临时放开时显式设置 `ALLOW_DEMO_CODE=true`；
- 成员忘记密码不用短信：管理员在「成员与角色管理」里「重置密码」，或在服务器上执行
  `docker compose exec web node scripts/reset-password.mjs <手机号> <新密码>`。

## 三、正式部署（腾讯云轻量服务器 + Docker）

### 1. 准备服务器

- 购买腾讯云轻量应用服务器（2 核 2G 起，Ubuntu 22.04）；
- 防火墙放行 80 / 443（用 IP 直连可只放行 3000）；
- 安装 Docker 与 Docker Compose。

### 2. 上传项目并启动

把 `绿茵BIT` 整个目录上传到服务器，然后：

```bash
cd 绿茵BIT
cp .env.example .env
# 编辑 .env：JWT_SECRET、SMS_MODE、短信密钥
docker compose up -d --build
```

访问 `http://服务器IP:3000` 即可。

### 3. 绑定域名 + HTTPS（推荐）

1. 域名解析 A 记录指向服务器 IP；
2. `.env` 增加 `DOMAIN=soccer.example.com`、`PUBLIC_PORT=3000`；
3. 启动 Caddy 自动申请证书：

```bash
docker compose --profile https up -d --build
```

访问 `https://soccer.example.com`。

> 如果使用中国大陆服务器 + 域名，需要 ICP 备案（一般 1–2 周）；用香港/海外服务器可免备案，但国内访问速度略慢。

## 四、数据持久化与云数据库

- 默认使用 SQLite，数据文件在 `./data/greensinbit.db`，已通过 Docker 卷持久化；
- 正式多实例部署建议切 PostgreSQL：

```bash
DB_DRIVER=pg
DATABASE_URL=postgres://user:pass@host:5432/greensinbit
```

并执行 `database/schema.sql`；报名学生卡照片建议接对象存储（腾讯云 COS / 阿里云 OSS）。

## 五、上线前安全清单

- [ ] `JWT_SECRET` 改为 64 位随机串，不使用默认值；
- [ ] `.env` 不提交到 Git；
- [ ] 短信 `SMS_MODE` 已切换为真实通道；
- [ ] 服务器防火墙只开放必要端口；
- [ ] 定期备份 `greensinbit.db`（或云数据库自动备份）；
- [ ] 公开链接前先用自己的手机号完整走一遍注册/登录/报名流程。

## 六、临时链接（今天就想发同学）

Windows 一键脚本（推荐）：

```powershell
.\scripts\start-public.ps1
```

不习惯 PowerShell 的话，直接双击 `scripts\start-public.bat` 也可以（cmd 方式）。

脚本会自动下载 Cloudflare Tunnel、启动服务并把公网链接写入 `public-url.txt`，同时打印在终端。停止：

```powershell
.\scripts\stop-public.ps1
```

手动方式（任意系统）：

在能运行本项目的电脑上：

```bash
# 启动服务
node server/src/index.js

# 另开终端，使用 cloudflared 生成临时公网链接
cloudflared tunnel --url http://localhost:3000
```

终端会输出一个 `https://xxxx.trycloudflare.com` 链接，直接发同学即可；电脑关机链接失效。
