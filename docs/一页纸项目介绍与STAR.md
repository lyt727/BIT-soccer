## 一句话定位（AI 价值主张）

**绿茵BIT = 用多模态大模型，把校园足球赛「纸质裁判报告 → 结构化业务数据 → 榜单」的线下人工链路做成可复用、可复核的 AI 数据管道。** 足球是第一个落地场景，能力本身可迁移到报名核验、成绩单、证照登记等任何「拍照即录入」的场景。

## STAR 叙事

- **Situation**：校内足球联赛每轮十余场，裁判赛后提交手写/打印裁判报告（双方名单、比分、进球、换人、红黄牌、裁判组）。录入每场约 **15–30 分钟**（估算口径，可换实测），榜单常滞后一天、易错难溯源。
- **Task**：独立从 0 做一款「报名→审核→抽签→排赛→AI 录分→榜单」全流程的赛事管理系统，并落地一个**真实可信、可复核**的 AI 识图能力。
- **Action**：
  1. **产品**：产出 PRD（用户/流程/异常/指标/开放问题 5 表），并以可运行 Demo 验证，而非停留在原型；
  2. **AI 方案**：视觉大模型结构化输出 + 候选名单约束降幻觉 + **人在回路**（低置信标红强制复核、未确认不落库）+ 审计留痕；Provider 抽象使 qwen-vl-max / GLM-4V / gpt-4o **一个 env 可切换**（含国产合规考量）；
  3. **工程自证**：零依赖 Node 全栈 + SQLite/PostgreSQL(RLS) 双驱动 + RBAC/审计 + 29 项接口冒烟测试全绿。
- **Result**（可自证 + 待补）：
  - 榜单 100% 由已完赛结果自动计算，**无双写不一致**；
  - 「未复核不落库」→ **0 脏数据**；每条 AI 识别可审计回溯；
  - 界面适配移动/桌面，PWA 可三端浏览器直接用；
  - 接口冒烟 **29/29** 通过；
  - 【AI 录分耗时与字段级准确率】待接真实视觉模型后实测（接入步骤见 `docs/AI产品决策说明.md §6`，评测方案 §5）。

## 我的角色

独立完成：**PRD → 高保真可运行 Demo → 前后端实现 → AI 方案与可靠性设计 → 测试 → 上线方案**（产品决策 + 关键实现）。

## 4 个可讲亮点（对 AI 产品岗）

1. **AI 可靠性来自流程而非模型**：阈值拒识 + 低置信标红强制复核 + 审计，回答「模型错了怎么办」；
2. **选型不被绑定**：Provider 抽象 + 国产模型合规考量，切换成本 ≈ 改 env；
3. **权限与合规**：RBAC 能力矩阵 + 赛事级指派 + 文件级鉴权 + 操作日志 + PostgreSQL RLS 兜底；
4. **数据一致性**：榜单为派生数据、实时重算，杜绝多表手工不同步。

## 可迁移场景（展示场景想象力）

纸质报名/材料核验、纸质成绩单/证书登记、赛后报告、报销单 —— 同一「拍照 → 结构化 → 落库 + 人在回路」管线。
